Privacy Policy — HaDeS Shortcuts

Local-first · No accounts · No tracking · No data sale

Applies to the web startpage and the Chrome extension (v1.0.0-rc-1).

HaDeS Shortcuts is a new-tab dashboard. It is local-first: your configuration and your data live in your browser. We do not operate servers, we do not run analytics, and we do not sell or share data with anyone.

1. Data stored on your device (only)

  • Dashboard configuration: shortcut layout, category visibility, theme, language, widget toggles. Stored in localStorage (web) or chrome.storage (extension).
  • Your notes and state: scratchpad text, Pomodoro/Focus session state, per-space preferences.
  • Local usage statistics: per-shortcut launch counts, streak days and peak hour, used for the on-dashboard analytics chart. Stored in localStorage, fully exportable and wipeable from Settings → Analytics. Never sent anywhere.
  • Weather city: the city you select for the weather widget.

2. Credentials you may enter (optional)

  • GitHub Personal Access Token: only if you enable encrypted dashboard backup. It stays in your browser and is used exclusively to read/write your own GitHub Gist. The dashboard payload is encrypted client-side with AES-256-GCM before upload. Create the token with gist scope only.
  • OpenAI / Anthropic API keys: only if you enable the AI assistant with a cloud provider. Keys live for the current tab session only and are sent only to the provider you chose.

3. Network requests (only when you use a feature)

No request is made for advertising, fingerprinting or third-party analytics. No third-party scripts are loaded; all code ships inside the page/extension package.

4. AI assistant context

When you send a query to a cloud provider, the request includes dashboard context you opted into (shortcut names, calendar entries, focus state, feed headlines) so answers are grounded in your setup. Nothing is sent unless you submit a query, and the only recipient is the provider you selected with your own key. The built-in local heuristic mode sends nothing.

5. Permissions (Chrome extension)

  • storage — persist your dashboard configuration locally.
  • activeTab — act on the current tab only when you explicitly save a shortcut or run a command.
  • topSites (optional) — import your most-visited sites as shortcuts, only if you enable it.
  • contextMenus (optional) — "Save to HaDeS Shortcuts" right-click item.

6. Your control

  • Export or wipe local analytics from Settings → Analytics.
  • Export, import or factory-reset all dashboard data from the backup section of Settings.
  • Removing your GitHub token or API key stops the corresponding integrations immediately.
  • Uninstalling the extension or clearing site data removes everything we store on your device.

7. Contact

Questions, correction requests or data concerns: open an issue at github.com/Devildonia/hades_shortcuts.
